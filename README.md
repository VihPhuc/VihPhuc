## 🚀 Featured project

### [CineHub](https://github.com/VihPhuc/cinehub) — Movie streaming SPA

A high-performance movie streaming app that aggregates multiple sources, built with **React 19 + TypeScript + Vite + Tailwind CSS 4**.

| Area | Highlights |
| --- | --- |
| **Features** | Browse movies, series, anime and TV shows; search and filter by genre/country; favorites, watch history and resume playback; shareable deep links for tabs, search, movie and episode. |
| **Video** | HLS playback with `hls.js`, automatic recovery policy, and iframe fallback for sources without `m3u8`. |
| **Performance** | In-memory + `sessionStorage` API cache with TTL, request deduplication, timeouts and abort support; code splitting keeps `hls.js` out of the initial bundle. |
| **PWA** | Installable app with a versioned service worker caching the app shell, API responses and images with size/TTL limits. |
| **Security** | DOMPurify sanitization, stream URL validation, sandboxed iframes, CSP and hardened production headers. |
| **Quality** | Vitest + jsdom tests, Oxlint, TypeScript strict build, and GitHub Actions CI covering build, bundle, deploy and encoding checks. |
